# Potential in the check

What this tool *could* become if it is used. Not a pitch. Not a weld.

---

**The fire it sits on.** Coding agents already open the PRs. Throughput went up. Review time and change-failure went up with it. The bottleneck moved from “who types” to “who is allowed to say yes.” That is how software is getting made in 2026. The agent aisle is taken. Judgment is not.

**What the tool actually is.** A fail-closed file: task, two git SHAs, commands, tests, files, claims, what it did not do, a hash two people recompute. YES or NO. Not a reviewer chatbot. CI already says tests passed. This is different: the agent has to bind **claims** and **non-claims** to bytes, or it does not get a yes.

**If it becomes a habit.** Every agent patch carries a pack. Humans stop reading vibes. Merge is pack-YES or it isn’t merge. That’s a default on the new factory floor — small, ugly, and in the path. Defaults on a new floor are how tools get paid, not how they get admired.

**If someone rents it.** A shop drowning in agent PRs pays for “this write does not land until a stranger can recompute the pack.” That’s a mouth, not a feature flag. Still a tools-company ceiling: the people who already pay GitHub/Cursor, not a new computer on a face.

**If it never leaves this chair.** You and the model check the pack on your own patches. Potential is personal: fewer rubber stamps. Not a business.

**Ceiling.** Real. Capped. This is not hands-in-the-room, not glasses, not watts. Those are bigger tails you cannot capture from a laptop. This can become the foreman on agent code. It cannot become the next home of the computer.

**How it dies.** A chat that says LGTM with a JSON costume. Occupancy: CodeRabbit, Copilot review, required CI, Bugbot. If the pack is optional, it loses. If the hash is theater, it loses. If you weld it to Nisaba with no paying job, it loses the other product too.

**Honest size.** Hunger: already here. Capture: only if YES is the door, not a badge. Buyer: not here yet. Potential is **becoming the door**, not becoming a dashboard.
