LAW — CITE THESE, NOT BLOGS
Right to make entry: 19 CFR 143.26(a)
  Owner or purchaser of the merchandise, or a licensed customs broker designated by the owner, purchaser, or consignee.
  Consignee who is not owner/purchaser (USPS, foreign postal operator, freight forwarder, carrier) CANNOT file. Broker must be IOR.

Bond / no-release: 19 CFR 145.15; 19 CFR 113.62 activity code 1; 19 USC 1623
  Basic importation and entry bond (STB or continuous) in ACE eBond BEFORE any activity.
  CBP FAQ (modified 2 Sep 2026): no standing or no bond → shipment not released from CBP custody.

Rail B — Entry Type 13 in ACE. PROD 22 Sep 2026. Voluntary test. No application.
  Same 143.26(a) filer class. Needs ACE filer code + IOR + activity-1 eBond.
  Required or ACE rejects: foreign postal operator tracking SE15 (S-10); shipper name SE30 and address SE35.
  Manifest Component Issuer Code = Secure Filing Postal (SFP).
  Eligible: all international-mail shipments ≤ $2,500 except quota / AD/CVD (those are formal). Includes PGA / Ch.98 / Ch.99 / FTA — this is where 22 Oct traffic goes.
  Error 325 = invalid USPS tracking. Error 331 = shipper required. Error 323 = value exceeded.

Rail C — Formal entry. Always for > $2,500, quota, AD/CVD. Alcohol/tobacco off Rail A.
