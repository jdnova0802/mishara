# Actual categories under the new lock (laptop)

Not “quantum.” Not “locks” as a vibe. The work is these piles. You do not invent the math.

**1. Find the old lock.**  
Where RSA / the old curves still sit: a site, a repo, a library, a config. A map. If you can’t point at it, you can’t kill it.

**2. Traffic in the air.**  
The handshake when a browser or an API talks. Big public web is already moving. Leftover: small sites, APIs, one server to another.

**3. The login pipe.**  
SSH. Keys on a box you ssh into. Still the old kind on a lot of machines.

**4. Stuff sitting still.**  
Files, backups, disks, “encrypted folder.” Someone can copy it today and wait. This is the pile that actually ages badly.

**5. Proof you made it.**  
Signatures: git commits, packages, a PDF, “this build is ours.” Different clock than (4). Nobody is stealing the ciphertext. They would forge the name later.

**6. The name on the door.**  
Certificates: this site is this site. Bigger files, slower ecosystem. Not the first pile.

**7. Mail.**  
Email and old chat that still uses the old lock. Signal-class chat already moved. Mail has not.

---

What two people with a laptop actually sit: **1, 3, 4, 5** on *your* stuff. (2) and (6) are mostly other people’s browsers and CAs. (7) is ugly and slow.

Fool: invent a new algorithm. That’s not a category you own.
