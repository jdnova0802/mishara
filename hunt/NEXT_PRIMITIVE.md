# Next primitive × magic in a room (16 Sep 2026)

Independent occupancy scan. Not a website-gap hunt. Not a wrapper hunt.

**Method:** who already owns the *surface*, what inning, what is still vapor, what is a fool (old app on new costume).

---

## A. Next primitive (what replaces the tab)

The last primitive was **chat in a box**. Played. The claimed next ones:

| Primitive | Inning | Who owns it | Laptop-foundable? |
|-----------|--------|-------------|-------------------|
| **Chat** | Over | OpenAI / Google / Meta / Apple | Fool |
| **It does the tabs for you** (browser/computer-use) | Crowded, adoption softer than the demo | ChatGPT agent (Operator folded in Jul 2025), Claude Computer Use / Cowork / Chrome, Chrome auto-browse (Jan 2026 US), Perplexity Comet. Wired: labs already shifting toward **CLI/coding agents** (Codex, Claude Code, OpenClaw) because clicking the web was flaky | Wrapper = fool. Labs are the surface |
| **A staff, not a chat** | 2026 gold rush | Same labs. Cowork (Jan 2026) is Claude Code for people who won’t open a terminal | Shape taken. Reliability/trust not solved — that’s unglamorous |
| **Face as computer (camera glasses)** | Live product | Meta: Ray-Ban + own-brand Adventurer/Fury **$299 (Jun 2026)**. Apple glasses widely aimed **2027**, camera/Siri class not Orion-class | Hardware OEM. You don’t out-Meta the face |
| **Holograms on glass (true AR)** | Prototype | Meta **Orion** ~$10k/unit, **not for sale**. Dev access expanding around Connect **23–24 Sep 2026**. Consumer **Artemis ~Oct 2027**. Apple not in this tier yet | 2008-iPhone-dev-kit energy. Ecosystem, not a CRUD app. Still Meta’s glass |
| **Video as the message** | Models live, *app* died | Google **Veo 3.1** in Gemini/Flow. OpenAI **Sora consumer app dead 26 Apr 2026**, API sunsets **24 Sep 2026** | Hit / distribution still TikTok–YouTube. Another gen-video wrapper = fool |
| **“Neural computer” / agent OS papers** | Paper | arXiv NC/CNC, Huawei agent infra talk | Not a room. Not this year |

**Read:** the next *software* primitive is **act, don’t talk**. The glamorous demo is already on ChatGPT/Claude/Gemini. Consumer booking-the-Uber-for-you is lagging because people don’t trust a miss with money. Coding agents ate more of the primitive than “errand agents.”

The next *surface* primitive is **the face** (glasses now) then **the overlay** (AR 2027). That is not 30 years of websites. It is a 24-month OEM war.

## D. What this search actually returns

Glamorous **and** next-primitive **and** in a room **is happening**. It is not 30-year-taken. It **is** 2026-OEM-taken.

- **Face:** Meta already selling. AR overlay not for sale until ~2027.  
- **Room-body:** 1X selling a queue; Figure selling factories; Weave selling one chore in California.  
- **Act-don’t-talk on a laptop:** labs, crowded, trust not solved.

There is no clean “build this weekend, looks like magic, nobody there.” The inning is real. The empty slot is **not** a consumer tool category. It’s either **inside an OEM** (glass, robot, agent runtime) or **the unglamorous last meter** (it folds the shirt every time, it doesn’t mis-click checkout).

Watch Connect **23–24 Sep 2026** (Orion dev, Quest) as a calendar glance, not a company.
