# Wealth equation (notes)

```
wealth  ≈  rent( skippable step of a machine that already runs )
           ×  how long you stay in the path
           ×  ( 1 if pulling you kills the act, else ~0 )

when the machine evolves:
  new_rent  =  skippable leftover on the new Tuesday machine
  not       =  empty industry
  not       =  the poster / screenshot of that era
```

**Easy English**

Don’t look for a vacant business. Look for a thing that already happens every week (money, steel, a filing, a patch). Crowded is good — it means someone already pays.

On that thing, find the step people skip. The pretty screen still works without you. That’s the hole.

Get paid to be the part they cannot skip. If they unplug you, it should not go / not file / not merge. That’s the rent.

Stay there long enough for the rent to compound. Money shows up after, not as the hunt.

When the world changes (new tools, new machines), don’t start over hunting “nobody does this.” Move to whatever they can skip on the *new* everyday machine. The famous logo of that era will already be taken. The leftover will be new.

Empty aisle = tourist. Pretty demo = poster. Wealth = rent on the leftover, held.
