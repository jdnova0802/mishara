# Occupancy of the seven piles (16 Sep 2026)

Ask: any **massive** leftover a laptop can sit. Not a 14th scanner. Not inventing math.

**Straight answer:** the overhaul is real and dated. The empty *aisle* is not. Enterprise already bought discovery. The primitives already shipped in OpenSSH, browsers, and `age`. What is left is clerk work, a cursed mail stack, and waiting on signatures.

---

**1. Find the old lock — taken.**  
IBM Quantum Safe / CBOMkit (open). SandboxAQ AQtive Guard. Then a pile of GitHub CLIs: PQCAnalyzer, pqc-migrator, `dotnet-cbom`. CycloneDX CBOM is a standard, not a hole.  
Fool: another scanner with a roadmap PDF.  
Leftover: none massive.

**2. Traffic in the air — taken.**  
Hybrid handshakes already in the browsers and the TLS libraries. `testssl` / SSL Labs already slap a site.  
Fool: a website that grades TLS and calls it quantum.  
Leftover: none you sit.

**3. The login pipe — mostly moved.**  
Current OpenSSH already does hybrid key agreement by default. The leftover is **host/user keys** (still the old signatures) and old boxes that never upgraded. OpenSSH is adding composite signatures as experimental. When that defaults, the pipe finishes without you.  
Fool: a new SSH.  
Leftover: “this jump host still warns” — a script, not a company.

**4. Stuff sitting still — tool exists, habit does not.**  
`age` 1.3 already encrypts to hybrid ML-KEM recipients (`age-keygen -pq`). GPG zip-password folders are still what people use.  
Fool: wrap `age` and rename it.  
Leftover: re-wrap *your* backups. Real. Not massive. Not a product aisle.

**5. Proof you made it — late, not empty.**  
Code/git/package signatures still mostly the old kind. Public Sigstore rails are not the new lock yet. That will move when GitHub/Sigstore flip. First week of that flip is a calendar, not a company you found tonight.  
Fool: a new “signed git” website.

**6. The name on the door — not you.**  
Certificates are CAs and browsers. RFCs exist. You do not become a CA from a laptop.

**7. Mail — emptiest, also cursed.**  
CMS/S/MIME RFCs for the new lock exist (2026). Thunderbird still tracking it as missing. Outlook/Apple are not a consumer PQC mail product. Building a mail client is a graveyard. A “PQC Gmail” is not a laptop win.

---

**Massive?** No pile is a massive empty category for two people.  
**Real hunger?** Yes — dated migration, auditors, “harvest the file today.” That money is already pointed at IBM-class discovery and at upgrading OpenSSH/`age`/browsers.  
**What you can actually do:** run `age -pq` on files you care about; upgrade SSH; do not ship scanner #14; do not invent an algorithm.

If you only keep one sentence: **the primitives shipped; the massive spend is someone else’s inventory dashboard.**
