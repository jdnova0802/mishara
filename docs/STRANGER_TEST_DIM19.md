# Dim 19 — 10-second stranger test (human, timed, cold)

**Engineering bar claimed ≠ measured.** This dimension stays UNVERIFIED until a human runs the protocol below and records the result.

## Rules

1. **Cold:** tester has never seen Gate / Bind Room / the `/for/*` plate. No briefing, no scorecard, no founder narrative.
2. **Timed:** phone stopwatch. Stop at 10.0 seconds. No “almost.”
3. **Surfaces (each run separately, fresh open):**
   - `https://gate.velaru.xyz/` (homepage)
   - `https://gate.velaru.xyz/bind-room`
   - one `https://gate.velaru.xyz/for/*` page (pick carriers **or** boards — record which)
4. **Device:** desktop browser, private window preferred. Mobile optional as a second pass — not a substitute.
5. **Pass criterion (all three surfaces):** within 10 seconds, stranger can say out loud:
   - what the product *stops* (irreversible bind / agent act), and
   - what cash door is offered (Bind Room price readable without scrolling past the first viewport), and
   - without needing lab jargon explained.
6. **Fail:** price missing/unclear, first viewport reads as dashboard/docs, borrowed clearinghouse names, or “I still don’t know what I’d buy.”

## Record sheet (copy per run)

```
Date (UTC):
Tester (no prior Gate context): Y/N
Surface URL:

Said cash door / price:
Jargon asked about:
PASS / FAIL:
Notes:
```

## What does *not* count

- Founder or agent running the timer while knowing the pitch
- Screenshot review without a stopwatch
- “Engineering bar” copy review alone
- Scoring the portfolio before this sheet is filled for all three surfaces
