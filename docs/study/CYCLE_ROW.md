# HOW TO LEARN

Lasswell + paperwork. Decoder lock for **any** cycle of contention (or any other cycle doc). Not a syllabus. Not Nisaba. Not tailored to one family.

A cycle is a thing that happened in time. Fill the row. If you cannot, you do not have a cycle yet — you have a story.

1. Who — role name (sovereign, oligarch, firm, union, church, party, PMC, cartel), not vibes
2. Does what — the act (evict, sanction, smear, shoot, tax, bless, certify)
3. To whom — target class / body / group
4. Under what authority — split the tag:
     cover:  flag / invoice / statute / procedure / docket
     medium: pulpit / paper / TV / For You / virality
     threat: fear / gun / chaos
     cloak:  privacy / classification / NDA
5. Date — as-of + provisional vs final

Then, or you still don’t have a fact:

6. With what effect — and who gets dinner after (required for a cycle; optional for one news row)
7. Receipt — **history first, table second**, both stranger-openable.
     history: archive / primary / monograph / statute-as-event / oral history
     table:   scale and live splitter (census, survey, event catalog, vital stats)
     Advocacy ≠ census. Poll-only is a dashboard. Sermon-only is a camp.
8. Falsifier — which cell dies first if you’re wrong (usually a historiographic fight, not a poll)
9. Grain — event ≠ campaign ≠ cycle (a post is not a century)
10. Resources / org — roster + budget. A role-noun is not an SMO

If 1–5 won’t fill: story.
If 1–5 fill and 7–8 won’t: clean story (worse).

A cycle doc still owes, or it is not PhD depth:

11. Method — how you know (process tracing / event catalog / survey / legal doctrine). Pick one. Know the bias of the catalog.
12. Periodization fight — when this cycle starts and ends is itself a claim
13. Comparison — one control case that is not this place and not this feed
14. Source criticism — who wrote the archive; silences; language of the file (not only English monographs)
15. Money / repression / space — 990s and dues; the state’s counter-repertoire; where the act happened

One crest + one fight + one historical file + one table + one method. Not a collection of slogans.
