Subject: Written comment — AI Risk Evaluation Supplement v6.0

Dear Mr. Sobel and Mr. Romero,

Please accept this written comment on AI Risk Evaluation Supplement version 6.0. Nisaba LLC commented on version 5.0 on September 14, 2026. This letter addresses four changes in version 6.0. It does not ask the Working Group to endorse a vendor. Nisaba has no customer using the system described below.

1. Exhibit C, item 3a. The clean draft asks: “Whether the use case(s) involve Agentic AI, and if so, identify its objectives, and authorizations without human approval.” A satisfactory answer should name the authorization that must exist before the action, the action the system may take under it, and the record an examiner can check without relying on the vendor’s account of what happened. If that authorization is missing, the action should not proceed. An objective statement alone does not answer 3a.

2. Generalized linear models. The clean draft says GLMs “are not without risk of causing unfair discrimination or other Adverse Consumer Impacts,” and then: “Based on existing regulatory oversight provided via rate making, regulators may choose to exclude some or all GLMs for Exhibit B through D related inquiries if appropriate.” The exclusion fits a GLM that is already inside a rate filing. It should not be read to drop a GLM that can produce an Adverse Consumer Impact outside that filing, including a denial, a bind, or a payment. Exhibit A should still show the GLM. The choice to skip Exhibits B through D should be recorded, with the reason.

3. “Adverse Consumer Impact.” Version 6.0 defines it as “an AI System decision (output) by an insurance company that is subject to insurance regulatory standards enforced by the Department that adversely impacts the consumer.” The earlier closing words, “in a manner that violates those standards,” are gone. That is the right scope for an exam. The examiner can ask for the decision record before anyone has established a violation. The definition should not be read the other way: an adverse decision is not, by itself, a violation.

4. Exhibit A inventory. Version 6.0 says a company with an existing inventory “should provide the AI System and/or Model inventory together with the completed Exhibit A,” rather than offering the inventory in lieu of the exhibit. For a use that involves agentic AI, the inventory row should state the action the system can take without human approval and where the authorization record is kept. A name and a model type are not enough for that row.
