How to read a row

Ethereum mainnet, Pool.liquidationCall only. No finding on commercial reasonableness. eth_call at block N is the post-state of that block. A health factor above 1 at the previous block is not an off-by-one: Aave only liquidates below 1, so the crossing can sit inside the liquidation block after an oracle update. The liquidation-block reading is after liquidationCall, not the mid-block trigger. This file does not trace. Bonus is Aave’s PercentageMath factor minus par: 10000 is 1.0×, so 10450 is 450 bps (4.5%), not a 104.5% bonus.
