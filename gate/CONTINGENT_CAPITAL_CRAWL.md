# Part C — PCT & international (over-crawl)

## C0 — Clock (do not invent dates)

| Event | Rule of thumb |
|-------|----------------|
| **Provisional → US non-provisional** | **12 months** from provisional filing |
| **Provisional → PCT** | Same **12-month** priority window (PCT claims provisional priority) |
| **PCT → national phase** | Typically **30/31 months** from **priority date** (country-dependent) |
| **Miss provisional anniversary with neither US utility nor PCT** | Priority path → **$0** |

**Owner action (S1):** Put **exact** provisional filing date + anniversary on calendar. This crawl is useless without that date.

---

## C1 — Strategies (pick one deliberately)

| Strategy | What you file by month 12 | Cost class | Upside | Downside |
|----------|---------------------------|------------|--------|----------|
| **US-only** | Non-provisional utility | Attorney + USPTO (quotes) | Cheapest; matches current GTM | No foreign priority later |
| **US + PCT** | US non-provisional **and/or** PCT (counsel designs) | US fees + PCT gov ~**$2–4k+** micro/small class + attorney | Buys ~18 more months to choose countries | Cash + complexity |
| **PCT-only then US national** | PCT by month 12 | PCT now; US national later | Defers some US exam spend | Still need attorney quality claims |
| **Skip convert** | Nothing | $0 | — | Patent path dead |

**Default doctrine:** **US convert first** (quotes week). Add **PCT only if** (a) conversion funded, (b) foreign licensee or EU/UK/JP desk is real within ~24 months, or (c) a grant/partner **requires** foreign filing. Do not PCT “for Absolute vibes.”

## C2 — PCT government fee sketch (USPTO as RO — order of magnitude)

Verify live on [USPTO PCT fees (USD)](https://www.uspto.gov/patents/basics/international-protection/patent-cooperation-treaty/pct-fees-us-dollars) before budgeting. Approximate **micro-entity** class (subject to change):

| Fee | Micro-ish ballpark |
|-----|-------------------|
| USPTO transmittal | ~$57 |
| USPTO search (ISA/US) | ~$480 |
| WIPO international filing (ePCT) | ~$1,416–$1,542 (not entity-discounted the same way) |
| **Gov subtotal** | often **~$2–3k** before attorney + extras |
| Later national phase (per country) | **$thousands–tens of thousands** each (translation + local counsel) |

**Attorney** for PCT + claims usually **dominates** government fees — get in the same quote email as conversion if you want a PCT rider number.
