## Why this is deeper *and* more useful than 24 random holes

PR #66 was archaeology + priesthood. Correct as far as it went. It was thin on:

1. **First-move.** A URL without a query is a homepage. Homepages are not rabbit holes.
2. **Knowledge engines that remain true** (SEP, nLab, OEIS, DLMF, ADS, Scaife, CDLI, Founders).
3. **Holdings maps** (WorldCat, Gallica, NARA, PRISMS, Pleiades, Rumsey) so you can *find the object*.
4. **Instruments next to priesthood** (eCFR *current text*, EDGAR, CourtListener, FRED, BIS, GLEIF) so shock mouths (ISDA, CLS, IANA) have somewhere to *work*.

SCP, tropes-only nights, and College of Arms stay available as satellites. They are not the core if the brief is **greatest + useful + informative + deepest**.

## Session choreography

1. **Warm (15 min):** K1 one SEP entry **or** A1 one unusual article. Three hops. Stop.
2. **Engine (60–90 min):** Stay inside **one** of K2 nLab, K6 Scaife, M1 one eCFR Part, or M3 one 10-K. No tab-hopping.
3. **Object (open-ended):** P1 / P4 / P6 facsimile of the thing the engine named.
4. **Mouth switch:** When language gets mushy → M6 BIS or M8 IANA. Read a procedure.
5. **Attic nightcap:** A6 or A8 **after** a primary. Attic first is candy.
6. **Hard rule:** Session spent on AltFTool / Random / satellites = failed lineup.

## Cross-walks (this is the “informative” part)

A lineup is a graph. Use it as one.

**What is money, actually?**  
SEP (economics / decision) → Founders (Hamilton, assumption) → eCFR Title 31 → FRED M2 → BIS CPMI → Unusual articles (Yap / Rai stones).

**Who may write the root of a name?**  
IANA root-zone process → GLEIF parent tree → the Title in eCFR that governs your string → WorldCat heading for the same string.

**Did this event happen, or was it only reported?**  
CourtListener docket → Federal Register notice → NARA RG → Wayback of the first claim → Lost Media Wiki if the artifact *is* the event.

**How did a 1978 machine boot?**  
Bitsavers vendor PDF → Discmaster ISO → Archive software → GE-97 contemporary web.
