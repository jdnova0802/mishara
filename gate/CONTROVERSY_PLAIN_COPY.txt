PART 0 — HOW THE WORLD WORKS (brief map. not a religion.)
========================================================================

CORE ENGINE
Incentives beat speeches.
Conspiracy is real sometimes.
Aligned mediocrity producing evil is more common than genius cabals.

POWER
Power = making your preferences other people's constraints.
Freedom for most people = choosing inside a cage they didn't build.
Legitimacy is violence + story + paperwork.
The state owns the license on force. Criminals own the gaps.
Soft harm (debt, eviction, smear, exclusion) can destroy as cleanly as fists.

REAL PYRAMIDS
CLASS: Sovereigns -> Capability lords -> Access/trust nodes ->
  Legible professionals -> Prompt/gig cognition -> Body/care class -> Surplus
VIOLENCE: Sovereign force -> contracted force -> economic/admin harm ->
  narrative/platform destruction -> illicit organized force ->
  intimate violence -> street chaos -> self-destruction
Street crime is the visible tip, not the system.

MONEY
Money is claim on energy, time, and obedience.
Capital compounds; wages linear.
Access is a drug. Rooms beat resumes.
Proof > potential. Receipts > mythology.

STATUS / INFO / TIME / TECH
Humans run on relative rank. Attention is currency.
Lies got cheap. Trust and verification got expensive.
Each cohort faces a different opportunity structure.
New tools create gold rushes, then consolidate into landlords.
The dark path is soft captivity with sharp edges.

WORKING STANCE
See pyramids clearly.
Don't worship predators; steal clean mechanisms only.
Build scarce leverage: proof, skills that move money, trusted rooms, options.
Capacity beats lucid despair.

ONE LINE
The world runs on incentives, force, status, and stories —
and the people who win learn which layer they're playing on.
