## S1 — Actus Fence teardown

### Who already ships
| Player | What they are | Gap vs Gate-shaped mouth |
|---|---|---|
| **Fidacy** | Mandate → Ed25519 grant → executor must redeem before pay; hash-chained audit | Strongest *payment* fence; MCP install ≠ host-wide intercept |
| **IntentFence** | ES256 receipt / preflight; never holds keys; x402 assess | Receipty; caller must enforce locally |
| **AgentPay-class MCP** | Caps + human approve + local sign | Ops wallet, not institutional stranger proof |
| **Visa Intelligent Commerce + Trusted Agent Protocol** | Agent tokens, passkeys, RFC9421 merchant recognition | **Network-scale** — not a startup mouth; defines the ocean |

### Open (narrow)
1. **Non-pay actus** (prod mutate, delete, irreversible email/legal send) under same grant grammar as pay.  
2. **Stranger verify URL** as first-class product (not only JWKS/audit proof APIs).  
3. **Bank/core send weld** (FedNow/RTP) — networks secure agent *commerce*; bank *push* still soft.

### Kill / don’t
- “Another MCP payment firewall” without executor-enforced grant + public receipt.
- Competing with Visa/MC agent token programs head-on.

### Weld
Desktop **S1 paste** is still correct — prove digest-bound DENY. Position as **grammar + receipt**, assume Fidacy/Visa exist.
