# Formula — Finding civilizational inventions (current era)

**Saved:** 2026-09-15  
**Use:** Run this before opportunity hunts. Invent bindings; don’t recycle last era’s scarcity.

---

## Meta-formula (one line)

**Civilizational invention = a new binding between a newly cheap force and a newly expensive constraint, enforced at a driver edge — fail-closed, stranger-verifiable, not a hub dashboard.**

---

## Why Google’s formula is outdated (as a search method)

Google’s era formula was not “search.” It was:

| | |
|---|---|
| **Cheap force** | Publish / hyperlink |
| **Expensive constraint** | Relevance |
| **Binding** | Rank the corpus (PageRank) |

That binding is saturated. New inventions need a **new binding**, not a better ranker, better feed, or better dashboard on the old scarcity (attention, relevance, ops).

**Trap:** Hunting “civilizational ideas” while still optimizing last era’s constraint.

## This era’s formula (Nisaba / Gate)

**When action is cheap, civilization needs a fail-closed, stranger-verifiable mouth between can and may — welded only at irreversible edges.**

| Law | Meaning |
|---|---|
| **PRI** | Inhibit unjustified irreversible acts |
| **Fail-closed** | Uncertainty ⇒ DENY (soft-yes under panic is the failure mode) |
| **Clearance ≠ execution** | Permission recorded ≠ act committed |
| **Stranger-verifiable** | Proof outside the actor’s trust boundary |
| **Driver edge** | Weld the irreversible commit (wire, gate, alert, release) — not the hub |

**First weld (named):** payout / withdraw — clear before wire. Prove DENY holds.  
**Not first:** own the grid, the model, the identity plane, or the gun.

## Discovery procedure (run in order)

### 1. Force scan
Name a capability that got ~**10–100× cheaper** in ≤15 years.  
Not a “market.” A **force**: act, generate, remote-commit, copy, aim, spend, allocate.

### 2. Constraint derive
Ask: *If this force scales 1000× unsupervised, what failure becomes civilizational?*  
Write the expensive constraint in one phrase (usually: irreversible wrong-act, unverifiable non-act, authority that soft-yeses).

### 3. Incumbent check
Are winners still selling the **previous** binding (rank, chat, monitor, dashboard, identity-only)?  
If yes → gap may still be open.

### 4. Edge pick
Locate where the **irreversible bit** actually happens.  
Examples: wire leave, canal-gate move, alert to air, sterile batch release, grid shed, organ commit.  
Skip hubs: SIEM, “AI governance platforms,” model cards without teeth.

### 5. Binding draft
Write a **one-line law** that sounds like physics, not a feature.  
Must include: fail-closed + independent proof + can≠may (or era-equivalent).

### 6. Stranger-proof test
If the company can soft-yes in private with no external check → not civilizational; compliance theater.

### 7. Own-the-stack reject
Mouths contribute under coordinators. Empires try to own the gun and stall. Prefer **driver-node contribution**.

### 8. Scale test
If every irreversible act in that domain used this binding, would continuity rise?  
- No → niche SKU  
- Yes → era-formula candidate  

### 9. Prove
One DENY (or equivalent) that **holds** on a real path. Museum demos don’t count.

```
FORCE (newly cheap):

NEW BINDING (one-line law):
DRIVER EDGE (irreversible commit locus):
STRANGER PROOF (what a third party can verify):
CROWDING (who sells the new binding vs the old):
BUILDABLE BY SMALL TEAM? (yes / partial / nation-scale only):
FIRST WELD (smallest real prove):
FILE AS: small-now / knowledge / skip
```

## How to grade findings

| Grade | Meaning |
|---|---|
| **Era formula** | New force + new constraint + new binding at driver edge; scale test passes |
| **Small-now weld** | Real edge; proves the binding; not itself the civilization |
| **SKU / sink** | Reuses binding; medium constraint (deletion receipt, labels) — ship if paid, don’t confuse with the mountain |
| **Knowledge** | Real + dated + nation/lab scale only — file, don’t own |
| **Skip** | Old scarcity, hub play, or crowded on the *new* binding already |

---

## Anti-patterns

- Better search / better chat / better monitoring for agents (= old formula on new force)
- Hub dashboards that never sit on the irreversible commit
- Soft-yes “human oversight” with no DENY that holds
- Self-attested compliance without stranger verify
- “Own identity / own the model / own the grid” as first move
- Hunting uncrowded niches *instead of* inventing bindings (uncrowded ≠ civilizational)
